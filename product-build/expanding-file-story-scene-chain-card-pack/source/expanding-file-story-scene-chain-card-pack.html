Expanding File Scene Chain Adult Guide

  • Set out the expanding file, blank page stack, pencils, and one labeled paper pocket before the adult-led story start: ____________________.
  • Choose one made-up scene chain card, then ask the child to keep every detail pretend and broad: ____________________.
  • Use each paper pocket for one page move: start scene, next scene, bridge detail, change marker, return detail, and file note: ____________________.
  • Keep the session offline and paper-only, with the adult holding the expanding file and guiding each page choice: ____________________.
  • Ask for invented characters, places, objects, and small changes; do not ask for personal facts or real day details: ____________________.
  • Close by tucking the page into the matching paper pocket and writing one adult-led restart note: ____________________.

Use one expanding file scene-chain card at a time. Keep every choice broad, invented, paper-only, and guided by an adult.
