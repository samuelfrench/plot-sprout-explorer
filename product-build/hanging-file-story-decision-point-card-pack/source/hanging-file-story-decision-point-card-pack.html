Hanging File Decision Point Adult Guide

  • Set out one hanging file, blank pages, pencils, and a decision-point card before the adult-led paper start: ____________________.
  • Choose one fictional character choice and keep every path, clue, and consequence note invented: ____________________.
  • Move through character choice, path one, path two, clue to compare, chosen path, consequence note, and hanging-file label in order: ____________________.
  • Keep the adult in charge of the hanging file while the writer writes or dictates short paper lines: ____________________.
  • Use pretend characters, broad places, and invented actions only; skip real names, real places, and personal facts: ____________________.
  • Close by reading the chosen path, adding one consequence note, and writing the hanging-file label for later adult-led paper planning: ____________________.

Use one hanging file card at a time. Keep every choice broad, invented, paper-only, and guided by an adult.

Choose the hanging file routine

short first-page setup

Character Choice Start

Hanging file, blank page, pencil, and character choice slip.

  1. The adult opens the hanging file and points to the character choice blank: ____________________.
  2. The writer names one fictional character for the paper plan: ____________________.
  3. The adult asks what choice is standing in front of that character: ____________________.
  4. The writer writes or dictates one character choice line on paper: ____________________.

The decision point starts with this fictional character choice: ____________________.

first option pass

Path One Fold

Hanging file, current page, pencil, and path one slip.

  1. The adult rereads the character choice line from the page: ____________________.
  2. The writer invents one path the fictional character could take: ____________________.
  3. The adult asks what makes path one clear on paper: ____________________.
  4. The writer writes path one on the slip and places it in the hanging file: ____________________.

Path one gives the character this possible choice: ____________________.

second option pass

Path Two Fold

Hanging file, path one slip, blank path two slip, and pencil.

  1. The adult points from path one to the path two blank: ____________________.
  2. The writer invents a different path the fictional character could take: ____________________.
  3. The adult asks how path two is different from path one: ____________________.
  4. The writer writes path two and tucks it beside path one: ____________________.

Path two gives the character this other possible choice: ____________________.

paper comparison pass

Compare Clue Sort

Hanging file, path one slip, path two slip, clue-to-compare note, and pencil.

  1. The adult lays path one and path two side by side on the table: ____________________.
  2. The writer chooses one clue to compare before a path is picked: ____________________.
  3. The adult asks what the clue shows about each path: ____________________.
  4. The writer writes the clue to compare on the note: ____________________.

The clue to compare says this about the two paths: ____________________.

choice close pass

Chosen Path Slip

Hanging file, two path slips, clue note, chosen path slip, and pencil.

  1. The adult rereads path one, path two, and the clue to compare: ____________________.
  2. The writer picks one chosen path for the fictional character: ____________________.
  3. The adult asks why that path fits the character choice: ____________________.
  4. The writer writes the chosen path on the slip: ____________________.

The chosen path for this decision point is: ____________________.

hanging-file wrap

Consequence Label Close

Hanging file, chosen path slip, consequence note, label strip, and pencil.

  1. The adult places the chosen path slip at the front of the hanging file: ____________________.
  2. The writer names one fictional consequence note for that chosen path: ____________________.
  3. The adult asks what hanging-file label will help find this decision point later: ____________________.
  4. The writer writes the consequence note and hanging-file label: ____________________.

The hanging-file label closes this decision point as: ____________________.
