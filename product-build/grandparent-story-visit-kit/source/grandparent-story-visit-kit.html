Host guide

Start the visit story

Visit setup

  • Print one host guide, six visit format cards, a postcard stack, and extra blank half-sheets before the visit table opens.
  • Place pencils, object choice slips, pretend place strips, and plain folders where the adult host can pass them out one step at a time.
  • Choose three ordinary object starters such as a button, spoon, seed packet, paper clip, teacup, or ribbon before the first story begins.
  • Prepare one quiet seat with a pencil, sketch space, and two simple choice strips for anyone who wants to join without speaking first.
  • Use color tabs, table symbols, or blank folders for sorting instead of personal labels.
  • Keep the kit screen-free by using only printed pages, spoken choices, sketches, pointing, and short written lines.

Story hosting

  • Open with an invented helper, a pretend place, and one ordinary object so the story starts in make-believe space.
  • Model one sample answer that is clearly invented, then invite writers to choose by pointing, sketching, dictating, or writing.
  • Move through the page in small cooperative steps: place, helper, object, small mix-up, next action, and calm ending.
  • Offer two adult-made choices when a writer pauses, and let the writer pick, change, combine, or invent a third option.
  • Keep sharing optional and focused on a title, object clue, sketch, or one invented sentence from the printed page.
  • Use gentle table language such as maker, guide, visitor, helper, messenger, keeper, or builder for every pretend role.

Quiet participation

  • Let a participant complete only one blank, circle one choice, or draw one clue and still count the page as finished.
  • Offer a silent postcard path where the writer fills the pretend place and object blanks before any table talk.
  • Allow an adult to write a dictated phrase while the writer chooses the words, points to options, or sketches the clue.
  • Accept a folded page, underlined word, or shown sketch as complete sharing when reading aloud is not preferred.
  • Keep a spare fresh page nearby so a writer can restart without explanation if the first idea feels too crowded.
  • Invite partners to trade only invented object ideas, not personal details, when they want a cooperative prompt.

No-data use

  • This kit uses invented helpers, pretend places, and ordinary objects; private facts are not needed.
  • Keep every page offline, printable, and handled by the host, writer, or household after the visit.
  • Do not collect private identifiers, personal labels, personal timelines, or household details.
  • Organize pages with symbols, colors, or plain folders instead of person-specific sorting.
  • Send finished work home or let the writer keep it at the table; the host does not need to retain copies.

Take-home handoff

  • Send home one finished visit page plus one optional story postcard for another screen-free writing moment.
  • Mark one simple next step such as add a title, add one setting detail, add one object clue, or finish the ending.
  • Tell households the postcard can be completed by pointing, sketching, dictating, or writing one short line.
  • Keep home sharing optional and focused on the printed page, invented place, ordinary object, title, or calm ending.
  • Invite the writer to save unused postcards for another table visit without requiring any follow-up report.

Pack reset

  • Return unused format cards and postcards to the host folder before clearing pencils and choice strips.
  • Place finished pages in plain take-home folders or let writers carry their own pages.
  • Restock blank pages, sharpen pencils, and replace bent choice strips before the next visit table.
  • Move used sample slips behind the host guide so the next host can begin with a fresh top card.
  • Write only a nonpersonal supply note if needed, such as more pencils, fewer object slips, or extra quiet pages.

Use one quest at a time. Keep every detail invented, printable, and offline.

Teacup Map Story

Best for: A cozy table visit where an adult host and writer want a pretend place before the first sentence.

  2. Writer adds an invented helper who visits that place for a small friendly errand: ____________________.
  3. Host offers two object choices and the writer picks one to become the clue: ____________________.
  4. Together they write one opening sentence and circle the detail to keep: ____________________.

Porch Lantern Postcard

  2. Writer sketches or writes one ordinary object waiting under the lantern: ____________________.
  3. Host offers a calm helper choice and asks what the helper notices first: ____________________.

Three-Chair Story Circle

Best for: Homeschool co-op family days with one adult host and a small group of mixed-age writers.

  1. Host labels three chair spaces as place, object, and helper, then asks writers to fill the first blank: ____________________.
  2. Each writer adds one invented object idea to the shared choice page: ____________________.
  3. Host reads the choices aloud and lets each writer pick a different path for a private page: ____________________.
  4. Writers finish with one calm ending line or one ending sketch: ____________________.

Tiny Shopkeeper Scene

Best for: A playful adult-led visit with pretend places, ordinary supplies, and cooperative sentence building.

  1. Host names an imaginary tiny shop and asks the writer what useful object sits in the window: ____________________.
  2. Writer invents a shopkeeper, helper, or visitor who needs that object for a kind task: ____________________.
  3. Host asks what small mix-up happens when the object is used in a surprising way: ____________________.
  4. Together they write one dialogue line and one next action: ____________________.
