Adult guide

Turning point coaching

File Box Turning Point Adult Guide

  • Adult-led setup: place the file box, blank pages, pencils, and one turning point card on the table before the writer begins: ____________________.
  • Adult-led framing: choose one fictional starting scene and keep every page paper-only, offline, and invented: ____________________.
  • Adult-led order: move from starting scene to turn signal, before path, after path, reaction, next step, and file-box label: ____________________.
  • Adult-led support: let the writer write or dictate short fictional lines while the adult keeps the file box sorted: ____________________.
  • Adult-led safety: use pretend characters, broad places, and invented actions instead of real names, exact places, or personal facts: ____________________.
  • Adult-led close: reread the turning point, add the next-step note, and write one file-box label for the paper stack: ____________________.

Use one file box card at a time. Keep every change broad, invented, paper-only, and guided by an adult.

Before Path Sort

  3. The adult asks which paper line belongs before the turning point: ____________________.
  4. The writer writes the before path note and files it behind the starting scene: ____________________.

after-the-turn pass

After Path Sort

File box, turn signal slip, after path note, and pencil.

  1. The adult slides the turn signal slip between the before path and the blank after path: ____________________.
  2. The writer invents what changes after the turn signal: ____________________.
  3. The adult asks how the after path is different from the before path: ____________________.
  4. The writer writes the after path note and places it after the turn signal: ____________________.
