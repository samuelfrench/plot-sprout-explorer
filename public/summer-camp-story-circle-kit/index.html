Parent steps

  1. Print only the activity pages needed for the week and keep the rest in a counselor folder.
  2. Choose one circle format before the group arrives so the activity starts quickly.
  3. Let children point, sketch, dictate, write, or pass during optional sharing.
  4. Use quiet option lines when a child wants to work privately instead of speaking to the group.
  5. Send home one trail card when the circle ends so families can extend the invented story offline.
