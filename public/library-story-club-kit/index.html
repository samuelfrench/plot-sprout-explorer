Parent steps

  1. Print one packet per participant plus a few spare draft pages.
  2. Choose one club routine and one session before the group starts.
  3. Let writers point, sketch, dictate, draft, revise, or pass during optional sharing.
  4. Mark one clear finish job on any unfinished page before it goes home.
  5. Reset the table supplies and save unused pages for the next club meeting.
