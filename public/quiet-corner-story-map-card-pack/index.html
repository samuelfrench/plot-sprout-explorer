Parent steps

  1. Choose one map routine before the activity starts.
  2. Set the paper, pencil, sketch, and imagination rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full sentence.
  4. Turn one broad pretend setting into a make-believe story clue rather than recording private place details.
  5. Send home one map slip with a single finish blank so families can continue the story offline.
