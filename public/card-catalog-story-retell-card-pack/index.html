Parent steps

  1. Print one retell card and set it beside a blank page.
  2. Ask for the beginning snapshot before asking for the middle clue.
  3. Let the child point, dictate, sketch, or write one short line per blank.
  4. Close with a card catalog label and save the next retell prompt for later.
