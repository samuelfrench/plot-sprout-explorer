Parent steps

  2. Set the paper, pencil, blank tray labels, and imagination rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full sentence.
  4. Turn one paper tray label into a fictional setting clue rather than using narrow real-world facts.
  5. Send one setting slip with a single finish blank so families can continue the story offline.
