Parent steps

  1. Print one packet per class set plus a few spare draft pages.
  2. Choose three to five stations before the day starts instead of using every page.
  3. Set out pencils, folders, and the first station page in one visible place.
  4. Let students point, sketch, dictate, write one line, or finish the page quietly.
  5. Collect finished pages in the folder and leave unused pages for the next session.
