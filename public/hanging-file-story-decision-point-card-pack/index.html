Parent steps

  1. Choose one decision-point routine before the activity starts.
  2. Set out the hanging file, cards, blank pages, pencils, and imagination rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full page note.
  4. Move from character choice to path one, path two, compare clue, chosen path, consequence note, and file label.
  5. Send one decision slip with a single blank so family adults can continue the paper choice offline.
