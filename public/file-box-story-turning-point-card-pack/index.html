Parent steps

  1. Choose one turning-point routine before the activity starts.
  2. Set out the file box, cards, blank pages, pencils, and imagination rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full page note.
  4. Move from starting scene to turn signal, before path, after path, character reaction, next step, and file-box label.
  5. Send one turning slip with a single blank so family adults can continue the paper turn offline.
