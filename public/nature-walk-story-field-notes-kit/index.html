Parent steps

  1. Choose one adult-approved observation spot and one field note page before the activity starts.
  2. Set the look, listen, point, and leave-living-things-undisturbed rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full sentence.
  4. Turn one broad detail into a make-believe story clue rather than recording exact place information.
  5. Send home one field card with a single finish blank so families can continue the story offline.
