Parent steps

  1. Print one resolution card and set it beside a blank page.
  2. Ask for a loose thread before asking for the last choice.
  3. Let the child point, dictate, sketch, or write one short line per blank.
  4. Close with an archive drawer label and save the next-story seed for later.
