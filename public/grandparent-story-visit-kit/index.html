Parent steps

  1. Choose one visit quest before the table starts so the activity stays simple.
  2. Print only the active quest pages and keep the rest in a host folder.
  3. Place pencils, blank cards, and one quest page where the adult helper can guide each step.
  4. Let participants point, sketch, dictate, write one line, or pass during optional sharing.
  5. Send home one postcard starter when the visit ends so families can extend the invented story offline.
