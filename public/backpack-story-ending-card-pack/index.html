Parent steps

  1. Choose one ending routine before the activity starts.
  2. Set the paper, pencil, blank backpack slips, and imagination rule before writing begins.
  3. Let the writer point, sketch, dictate, write one word, or fill one blank before asking for a full final sentence.
  4. Turn one pretend backpack clue into a fictional ending detail rather than using narrow real-world facts.
  5. Send one ending slip with a single finish blank so families can continue the story offline.
